## 4-Block Slide Layout (Ready to Copy to Slides)

### 1. PROGRAMMING LANGUAGES
* **Python 3.14:** Core language for the backend, optimization algorithms, and machine learning pipelines. Chosen for high-performance scientific libraries and fast mathematical modeling.
* **JavaScript (ES6+) / TypeScript:** Client-side language powering real-time geospatial rendering, dynamic route recalculations, and telemetry updates.
* **HTML5 & CSS3:** Semantic web structure and responsive dark-mode styling with high visual accessibility.
* **SQL & JSON Data Contracts:** High-speed data modeling for AIS vessel coordinates, port queues, and CRIS rail matrices.

### 2. FRONTEND & GEOSPATIAL MAP STACK
* **Leaflet.js:** High-performance, lightweight GIS mapping library rendering nautical ship tracks, port congestion heat beacons, and Indian Railways freight corridors.
* **Esri World Dark Gray GIS:** Watermark-free, high-contrast dark GIS canvas designed for institutional maritime operations.
* **Tailwind CSS:** Modern utility-first styling engine ensuring responsive layouts across desktop command centers, tablets, and phones.
* **Chart.js:** Real-time interactive charting library displaying 30-day BDI/BCI predictions with P10/P50/P90 confidence intervals.
* **Lucide Icons:** Clean, production-grade vector UI iconography.

### 3. BACKEND & WEB SERVER
* **FastAPI (Python):** Modern, high-performance ASGI web framework running on Python 3.14 async event loops. Delivers sub-150ms optimization calculations.
* **Uvicorn:** Lightning-fast ASGI production web server.
* **Pydantic v2:** Robust data validation, schema enforcement, and serialization for live AIS feeds and FOIS railway tariffs.

### 4. AI, MACHINE LEARNING & MATH SOLVER
* **PuLP & COIN-OR CBC:** Mixed-Integer Linear Programming (MILP) solver executing the Total Landed Cost (TLC) minimization model.
* **XGBoost & Scikit-Learn:** Gradient-boosted decision trees for 14–30 day Baltic Dry Index freight rate forecasting.
* **NumPy & SciPy:** Fast vectorized numerical processing for maritime distance and fuel burn models.
* **Vercel Serverless & Edge CDN:** Global edge deployment with automated CI/CD directly from GitHub.
