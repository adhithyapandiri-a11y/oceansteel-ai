2. FRONTEND & GEOSPATIAL MAP STACK USER INTERFACE
•
Leaflet.js: Lightweight, ultra-responsive GIS mapping engine rendering live nautical vessel tracks, port beacons, and rail freight corridors.
•
Esri World Dark Gray Canvas: Watermark-free, high-contrast dark cartographic base tile service optimized for maritime operations centers.
•
Tailwind CSS Architecture: Production utility-first design system ensuring pixel-perfect layout fidelity across laptops, tablets, and field displays.
•
Chart.js: Interactive visualizer plotting 30-day Baltic Dry Index (BDI) and Baltic Capesize Index (BCI) freight forecast curves.
3. BACKEND SERVER, APIS & PROTOCOLS INFRASTRUCTURE
•
FastAPI (Python): High-throughput ASGI web framework running on Python async event loops, delivering sub-150ms optimization responses.
•
Uvicorn: Lightning-fast ASGI production web server for local demonstrations and enterprise containerized execution.
•
Pydantic v2: Strict data validation, schema enforcement, and type safety for live maritime vessel telemetry and railway rake matrices.
•
REST & WebSocket APIs: Low-latency streaming bridge fusing real-time AISStream maritime positions with Indian Railways FOIS rake updates.
4. AI, MATHEMATICAL SOLVER & DEPLOYMENT ALGORITHMS
•
PuLP & COIN-OR CBC: Mixed-Integer Linear Programming (MILP) solver executing the Total Landed Cost (TLC) minimization model.
•
XGBoost & Scikit-Learn: Gradient-boosted machine learning model trained on historical Baltic indices for 14–30 day forward freight forecasting.
•
NumPy & SciPy: High-performance vectorized numerical processing for maritime haversine distance matrices and fuel burn curves.
•
Vercel Edge & GitHub: Serverless cloud deployment with zero-latency global edge caching and automated Git CI/CD synchronization.
