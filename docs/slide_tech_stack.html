1. PROGRAMMING LANGUAGES CORE TECH
• Python 3.14: Core language for the backend server, mathematical solvers, and AI pipelines.
• JavaScript (ES6+) / TypeScript: Powers the interactive web dashboard, real-time map updates, and telemetry ticker.
• HTML5 & CSS3: Provides semantic layout structure and responsive dark-mode styling.
• JSON / GeoJSON: High-speed data contracts connecting maritime AIS coordinates and Indian Railways tariffs.
2. WEB & GEOSPATIAL MAP STACK USER INTERFACE
• Leaflet.js: Lightweight, high-performance GIS library that renders nautical ship tracks and rail corridors.
• Esri World Dark Gray Canvas: Clean, watermark-free dark GIS map designed for institutional command centers.
• Tailwind CSS: Modern utility-first styling engine ensuring responsive layouts across laptops and tablets.
• Chart.js: Interactive time-series charts rendering 30-day Baltic Dry Index (BDI) forecast curves.
3. BACKEND SERVER & APIS ENGINEERING
• FastAPI (Python): High-throughput ASGI web framework delivering fast sub-150ms optimization calculations.
• Uvicorn: Lightning-fast ASGI server for production and local execution.
• Pydantic v2: Strict schema validation for incoming vessel coordinates and train freight rates.
• REST & WebSocket APIs: Standard protocols connecting AIS ship telemetry with Indian Railways FOIS.
4. AI, MATH SOLVER & DEPLOYMENT ALGORITHMS
• PuLP & Google OR-Tools: Mixed-Integer Linear Programming (MILP) solver used to minimize Total Landed Cost.
• XGBoost & Scikit-Learn: Gradient-boosted machine learning model for 14–30 day shipping freight rate forecasting.
• Vercel Cloud & Edge CDN: Serverless Python API hosting and global static deployment directly from GitHub.
• Git & GitHub: Distributed version control and automated continuous deployment.
